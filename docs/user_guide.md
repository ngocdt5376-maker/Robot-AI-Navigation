# Hướng dẫn sử dụng

1. Cài Python 3.10 trở lên và các thư viện trong `requirements.txt`.
2. Chạy `python scripts/run.py`.
3. Chọn Map 1/2/3 và Weighted A*/LRTA*.
4. Dùng Start để chạy tự động, Pause để dừng, Step để đi từng bước, Reset để khởi tạo lại.
5. Bật ML nếu mô hình đã sẵn sàng; lần chạy đầu có thể mất thời gian huấn luyện.
6. Kéo thanh Tốc độ và Hệ số w để điều chỉnh mô phỏng.
7. Kéo xuống phần So sánh thực nghiệm và nhấn nút chạy cả hai thuật toán trên ba bản đồ.
